# Fake News Detection using Transformers with Explainable AI

**Team:** Messai Salah Eddine, Dali Oussama, Toumi Mohamed, Alem Nadjemeddine  
**Course:** NLP Deep Learning Term Project  
**Date:** May 2026

## Project Overview
This project implements a fake news detection system using transformer models (DistilBERT, RoBERTa) with progressive fine-tuning and LIME explanations. The best model achieves **95.3% accuracy** on the LIAR dataset.
